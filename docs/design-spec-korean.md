# EZIO — 추가 콘셉트 설계 명세 (Concept 05 · 06: 한국 기업 스타일)

> 기존 4개 콘셉트(원페이지 스크롤)는 유지한다. 이 문서는 **한국 기업 홈페이지 문법**을 따르는
> 멀티페이지 콘셉트 2개의 명세다. 콘텐츠는 동일하게 `docs/shared-content/content.ts`를 사용한다.

---

## 공통 (두 콘셉트 모두)

### 기술
- Vite + React 18 + TypeScript + Tailwind CSS v4 (`@tailwindcss/vite`), yarn — 기존 콘셉트와 동일
- **멀티페이지**: `react-router-dom` v6 + **HashRouter** (GitHub Pages 정적 배포 호환, `base: './'` 유지)
- 페이지 전환 시 스크롤 최상단 리셋 (ScrollToTop 컴포넌트)
- KO 기본 + KO/EN 토글 (기존과 동일한 LanguageContext 패턴)
- 폰트: Pretendard (+ 시스템 fallback). 장식 serif가 필요하면 Noto Serif KR 소량만.

### 비주얼 아트워크
- `docs/shared-visuals/scenes/` 의 장면 일러스트 컴포넌트를 `src/components/scenes/`로 복사하여 사용
- 슬라이더/서브비주얼/페이지 히어로에 적극 사용 (플레이스홀더 느낌 금지)
- tone은 콘셉트 팔레트에 맞게 선택

### 정확성 규칙 (기존과 동일 + 추가)
- 기존 금지 규칙 전부 유지 (파트너 등급, GS칼텍스 실명, 가짜 수치, 쇼핑몰 UI)
- **전화번호/팩스/이메일 임의 생성 금지** — 확인된 연락처가 없으므로 "문의 폼" 유도로 대체
- 게시판(공지사항 등) 데모 항목은 각 행 또는 목록 하단에 "데모 게시물" 표기, 실제 뉴스처럼 보이는 제목 금지
  (예: "홈페이지를 새롭게 오픈했습니다" 정도의 중립적 항목 + 데모 표기)
- 카탈로그 "다운로드" 버튼은 데모 비활성 처리 (실제 파일 없음 명시 툴팁/라벨)
- 연혁·인사말은 content.ts의 confirmed/placeholder 구분 유지

## CONCEPT 05 — KOREAN ENTERPRISE (`concept-05-korean-enterprise/`)

**Theme**: LS ELECTRIC 스타일 대기업 제품 포털. 조사된 LS ELECTRIC의 **레이아웃 문법을 그대로 재현**하되,
로고·이미지·텍스트·CI 컬러는 절대 복제하지 않는다 (레이아웃 구조만 벤치마크, 브랜딩은 EZIO).

### 팔레트
- 화이트 기반 + EZIO 로열 블루 `#0B4DA2` (LS 그린 사용 금지 — 브랜드 모방 회피)
- 보조: 그레이 `#F4F6F8`, 라인 `#DDE3EA`, 텍스트 `#222B36`
- 포인트로 스카이블루 `#2F80DE` 그라디언트 (메인 슬라이더/버튼)

### 레이아웃 문법 (LS ELECTRIC 구조 재현 — 핵심)
1. **상단 유틸리티 바** (얇은 그레이): 언어 토글(KO/EN), 사이트맵 링크
2. **GNB + 메가메뉴**: 로고 좌측, 메뉴 [회사소개 / 제품 / 솔루션 / 프로젝트 / 고객지원].
   hover 시 **전체 폭 메가메뉴 패널**이 펼쳐지며 전 메뉴의 하위 항목이 컬럼으로 한번에 노출.
   메뉴 하단 2px 블루 인디케이터.
3. **메인 비주얼 슬라이더**: 풀와이드, 3개 슬라이드 (장면 아트워크 배경 + 좌측 대형 카피 + CTA 버튼),
   자동 롤링(6초) + 좌우 화살표 + 하단 인디케이터(바 형태) + 일시정지 버튼. `prefers-reduced-motion` 시 자동롤링 중지.
4. 메인 하단 순서:
   - **제품 카테고리 퀵 카드** 4개 (아이콘형 카드 → 제품 페이지 카테고리로 이동)
   - **솔루션 하이라이트** (5개 솔루션 탭 또는 카드)
   - **프로젝트/기술역량 밴드** (Featured Project 링크)
   - **공지·자료 2컬럼 박스** (공지사항 목록 + 카탈로그/자료 안내 — 데모 표기)
5. **푸터**: 다층 구조 — 상단 링크 컬럼(회사소개/제품/솔루션/고객지원 사이트맵), 하단 회사정보 + 데모 고지

### 페이지 구성 (HashRouter)
- `/` 메인
- `/company` 회사소개: 서브비주얼 + 개요 + Company Facts + 연혁(확인분만) + CEO 메시지(placeholder 표기)
- `/products` + `/products/:categoryId` 제품: **좌측 LNB 카테고리 트리**(현재 카테고리 하이라이트) + breadcrumb
  + 우측 제품 카드 그리드 (제품명 + 짧은 설명 + "카탈로그 데모" 비활성 버튼). LS식 "카테고리 → 제품 리스트" 문법.
- `/solutions` 솔루션: 5개 솔루션 상세 (LS식 기능 서술형 톤)
- `/projects` 프로젝트: Featured Case + 산업군 4개 + 프로세스 8단계
- `/support` 고객지원: 공지사항 게시판 목록(데모) + 문의 폼(Contact)
- **서브페이지 공통 패턴**: 상단 서브비주얼 밴드(페이지명 + 장면 아트워크 배경) → breadcrumb (홈 > 1차 > 2차)
  → 좌측 LNB(해당 섹션 메뉴 트리) + 우측 콘텐츠. 이것이 한국 대기업 사이트의 핵심 문법이므로 반드시 재현.

### 모바일
- GNB → 햄버거 풀스크린 드로어(아코디언 메뉴), LNB → 상단 가로 스크롤 탭으로 변환, 슬라이더 스와이프 대응(버튼 유지)

## CONCEPT 06 — KOREAN CLASSIC (`concept-06-korean-classic/`)

**Theme**: 2000년대 후반~2010년대 전형적인 한국 중소·중견 제조/설비 기업 홈페이지.
"오래 거래한 믿음직한 회사" 느낌. 세련미보다 **익숙함과 신뢰**가 목적.

### 팔레트
- 클래식 코퍼레이트 블루 `#1B5AA6` + 딥 네이비 `#153A66`
- 배경 화이트 + 연회색 `#F2F4F7`, 각진 박스 + 1px 실선 테두리 `#D5DBE3`
- 배너는 블루 그라디언트 + 장면 아트워크 합성

### 레이아웃 문법 (한국 클래식 기업 사이트 재현 — 핵심)
1. **헤더**: 좌측 로고(EZIO + 한글 회사명 병기), 우측 GNB [회사소개 / 사업분야 / 제품소개 / 수행실적 / 고객센터],
   최상단 얇은 유틸바(언어 토글). GNB hover 시 단순 드롭다운(메가메뉴 아님 — 클래식 스타일).
2. **메인 비주얼 배너**: 블루 그라디언트 + 장면 아트워크, 큰 한글 카피 ("산업을 움직이는 안정적인 전력 솔루션"),
   3장 슬라이드 자동 롤링 + 동그란 인디케이터.
3. **메인 하단 클래식 그리드** (박스 4개):
   - 회사소개 바로가기 배너 (이미지 + "CEO 인사말 보기")
   - 사업분야 아이콘 4~5개 그리드
   - 공지사항 리스트 박스 (제목 + 날짜, "+" 더보기 — 데모 게시물 표기)
   - **프로젝트 문의 박스** (전화번호 대신 "온라인 문의" 큰 버튼 — 전화번호 임의 생성 금지)
4. **우측 플로팅 퀵메뉴**: [문의하기 / 오시는길 / TOP] 세로 버튼 스택 (스크롤 시 고정)
5. **푸터**: 네이비 배경, 회사정보 한 줄(주소·대표자), 데모 고지, 카피라이트

### 페이지 구성 (HashRouter)
- `/` 메인
- 회사소개: `/about/greeting` 인사말(CEO 메시지 — placeholder 표기 유지, 대표 성함), `/about/overview` 회사개요
  (**클래식 회사개요 테이블**: 회사명/대표이사/설립일/소재지/사업분야/자본금(2022년 기준) — 확인된 정보만),
  `/about/history` 연혁 (연도 테이블 — 확인분 + placeholder 행), `/about/location` 오시는길
  (지도 스타일 placeholder 박스 + 주소 + "지도 API 연동 예정" 표기)
- `/business` 사업분야: 5개 솔루션 (아이콘 + 서술)
- `/products` 제품소개: 카테고리별 목록 (LNB + 표/카드 혼합, 가격 없음)
- `/works` 수행실적: Featured Project 상세 + 프로세스
- `/support` 고객센터: 공지사항 게시판(클래식 테이블형: 번호/제목/날짜 — 데모 표기) + 온라인 문의 폼
- **서브페이지 공통 패턴**: 좁은 서브비주얼 바(페이지 타이틀, 블루 그라디언트) → breadcrumb → **좌측 LNB 세로 메뉴**
  (선택 항목 블루 하이라이트) + 우측 콘텐츠. 콘텐츠 제목은 좌측 블루 바 장식(`▎`) 스타일.

### 스타일 디테일 (올드스쿨 문법)
- 각진 모서리(라운드 0~2px), 테이블 다용 (회사개요/연혁/게시판)
- 제목 앞 블루 사각 불릿, 섹션 타이틀 아래 이중 밑줄(굵은 블루 + 얇은 그레이)
- 버튼: 그라디언트 블루, 각진 형태
- 애니메이션 최소 (슬라이더 외 없음)
- 단, 코드 품질과 반응형은 현대적으로 (구식은 어디까지나 시각 문법)

### 모바일
- GNB → 햄버거 드로어, LNB → 셀렉트박스 또는 가로 탭, 퀵메뉴 → 하단 고정 바로 변환
