# 2. 회사 및 사업 이해

## 2.1 회사 기본 정의

EGO는 LS ELECTRIC 대리점으로 영업하며, LS ELECTRIC의 전기 및 시스템 관련 완제품을 고객에게 공급하는 회사다. 고객 요구사항 확인, 제품·사양 검토, 견적, 판매, 발주, 납기와 납품 관리, 현장 요청 대응, 제품 장애 접수 및 제조사 연계 A/S 지원을 담당한다.

EGO는 특히 GS칼텍스 현장에 공급되는 LS ELECTRIC 시스템 및 전기 제품 관련 업무를 전문적으로 담당해 온 경험이 있다. 이때 GS칼텍스는 EGO의 주요 고객이자 대표 수행 경험이며, EGO의 사업 부문·공급 브랜드·계열사로 표현하지 않는다.

회사명의 영문 의미는 공식 표기가 추가 확인되기 전까지 사용자가 제공한 Energe Goes On을 그대로 사용한다. Energy Goes On 등으로 교정하거나 변형하지 않는다.

## 2.3 고객에게 설명할 사업 흐름

**LS ELECTRIC 제품 → EGO의 상담·견적·판매·발주·납품 관리·현장 대응 → 고객사의 제품 도입과 운영 지원**

이 흐름은 홈페이지와 사업영역 페이지에서 반복하되, 다음처럼 쉽게 풀어 쓴다.

> “EGO는 고객이 필요로 하는 LS ELECTRIC 제품을 확인하고 견적과 주문을 진행합니다. 이후 제조사 납기 확인, 납품 관리, 현장 요청 대응과 제품 관련 A/S 연계까지 고객 접점을 이어갑니다.”

### 별도 확인 없이 주장하지 않을 역할

- 전기공사 직접 수행

- 설치·배선·시운전 직접 수행
- GS칼텍스 공식 협력사 또는 독점 공급사
- LS ELECTRIC 공식 인증 서비스센터
- 모든 LS ELECTRIC 제품 취급
- 모든 장애의 직접 수리 또는 교체 보장

# 3. 콘텐츠 작성 원칙

## 3.1 사이트 핵심 목적

1. 방문자가 EGO의 회사 정체성과 역할을 짧은 시간 안에 정확히 이해하게 한다.
2. LS ELECTRIC 제품 구매를 검토하는 기업 담당자가 상담과 견적을 요청하게 한다.
3. 기존 고객이 제품 문의, 현장 요청, A/S 접수와 기술자료 확인 경로를 쉽게 찾게 한다.
4. 주요 고객과 수행 경험을 과장 없이 제시해 거래 신뢰를 높인다.
5. 구직자가 EGO의 업무 방식과 채용 정보를 확인하게 한다.

## 3.2 방문자가 사이트를 보고 이해해야 하는 세 가지

1. **EGO는 무엇을 공급하는가**
   EGO는 LS ELECTRIC의 전기 및 시스템 관련 완제품을 고객 요구에 맞춰 상담·견적·판매한다.

2. **EGO는 공급 과정에서 무엇을 담당하는가**
   EGO는 주문과 발주, 제조사 납기 확인, 출고·납품 관리, 현장 요청 대응을 이어서 관리한다.

3. **납품 후 어떤 지원을 받을 수 있는가**
   EGO는 제품 관련 문의와 장애를 접수하고, 필요한 경우 LS ELECTRIC 또는 관련 기술조직과 협의해 A/S 진행을 지원한다.

## 3.3 문체와 문장 기준

- 전문적이고 신뢰감 있는 B2B 산업재 문체를 사용한다.
- 한 문장에는 하나의 핵심 정보만 담고, 고객이 이해하는 업무 용어를 사용한다.
- “무엇을 한다” 다음에 가능하면 “고객에게 어떤 편익이 생기는지”를 연결한다.
- 추상적인 가치보다 제품 확인, 견적, 납기, 납품, 현장 요청, 장애 접수처럼 실제 업무를 먼저 보여준다.
- “영업·수주 지원”은 고객 관점에서 “요구사항 확인과 견적 대응”, “주문 및 발주 관리” 등으로 풀어 쓴다.
- “기술지원”은 직접 설계·공사·수리를 뜻하지 않도록 “제품 관련 확인과 제조사 기술지원 연계”로 범위를 명확히 한다.
- “파트너”라는 단어는 계약상 공식 명칭이 확인된 경우에만 사용한다.

## 4.3 메뉴 운영 원칙

- 대표이사 인사말은 독립 메뉴로 만들지 않고 EGO 소개 안에 짧게 포함한다.
- 경영진 소개는 인물 정보와 공동 메시지에 집중해 대표이사 메시지와 중복되지 않게 한다.
- 연혁 및 주요성과 메뉴는 만들지 않는다. 설립연도 등 핵심 사실이 확인되면 EGO 소개의 회사 개요에만 표시한다.
- 오시는 길은 사업장 소개에만 포함한다.
- GS칼텍스 수행실적을 별도 하위 메뉴로 만들지 않고 주요 고객·수행실적 페이지 안에 배치한다.
- 채용정보는 한 페이지 안에서 인재상, 직무, 절차, 공고를 구분한다.

# 8. 사업영역 콘텐츠

사업영역의 세 페이지는 서로 분리되어 있지만 하나의 연속된 고객 경험으로 읽혀야 한다.

## LS ELECTRIC 제품 공급

### 1. 페이지 목적

EGO가 LS ELECTRIC 제품을 어떤 방식으로 상담·견적·판매하고, 주문 이후 발주와 납품을 어떻게 관리하는지 설명한다. 고객이 문의 전에 준비할 정보와 공급 절차를 이해하고 제품·견적 문의로 이동하게 한다.

### 2. 주요 방문자

- LS ELECTRIC 제품의 구매 또는 견적을 검토하는 기업 담당자
- 필요한 제품은 있으나 정확한 모델이나 사양 확인이 필요한 실무자
- 수량, 납기와 납품 조건을 확인하려는 구매 담당자
- 기존 제품의 대체 또는 추가 구매를 검토하는 고객

### 3. 핵심 메시지

1. EGO는 고객 요구사항을 먼저 확인한 뒤 취급·공급 가능 여부와 제품 사양을 검토한다.
2. 견적, 주문, 제조사 발주, 납기 확인, 출고와 납품을 하나의 공급 흐름으로 관리한다.
3. 구체적인 취급 품목은 확인된 제품군만 공개하며, 모든 LS ELECTRIC 제품을 취급한다고 주장하지 않는다.

### 4. 메인 영역

- **메인 제목:** “필요한 LS ELECTRIC 제품을 정확히 확인하고 공급합니다”

# 10. 고객지원 콘텐츠

고객지원은 회사 홍보보다 방문자의 행동 완료가 우선이다. 각 페이지의 첫 화면에서 무엇을 접수할 수 있는지, 무엇을 준비해야 하는지, 접수 후 어떤 순서로 확인되는지를 명확히 보여준다.

## 제품·견적 문의

### 1. 페이지 목적

신규 또는 기존 고객이 제품 구매, 견적, 납기, 취급 여부와 대체 제품 검토 요청을 필요한 정보와 함께 접수하게 한다. 정확한 모델을 모르는 방문자도 부담 없이 문의할 수 있도록 안내한다.

### 2. 주요 방문자

- LS ELECTRIC 제품의 가격과 공급 가능 여부를 확인하려는 구매 담당자
- 제품 모델·사양 검토가 필요한 설비·현장 담당자
- 기존 제품의 추가 구매나 대체 가능성을 문의하는 고객
- 납기, 수량, 납품 장소와 현장 조건을 상담하려는 고객

### 3. 핵심 메시지

1. 제품명, 모델, 사양, 수량과 희망 일정을 제공하면 더 정확한 확인이 가능하다.
2. 정확한 제품을 모르더라도 사용 목적과 기존 제품 정보를 바탕으로 문의할 수 있다.
3. 접수 후 EGO가 내용을 검토하고 추가 정보가 필요하면 연락한 뒤 견적·공급 가능 여부를 안내한다.

### 4. 메인 영역

- **메인 제목:** “제품·견적 문의”
- **보조 문구:** “필요한 제품, 사양, 수량과 희망 일정을 알려주세요. 확인 후 취급·공급 가능 여부와 견적 절차를 안내드립니다.”
- **CTA:** “문의 작성하기”
- **보조 안내:** “정확한 모델을 모르시면 사용 목적과 기존 제품 사진을 보내주세요.”

## 16.3 주체별 금지 오인

### LS ELECTRIC 관련

- EGO가 LS ELECTRIC 제품을 제조·개발한다고 쓰지 않는다.
- LS ELECTRIC의 모든 제품과 서비스를 EGO가 제공한다고 쓰지 않는다.
- 대리점 계약상 명칭을 확인하지 않고 공식 파트너·공식 총판·인증센터로 바꾸지 않는다.
- 제조사 공식 자료의 문구와 이미지를 EGO 소유 콘텐츠처럼 사용하지 않는다.

### GS칼텍스 관련

- 고객 관계를 계열·공동 사업·전략적 제휴 관계로 확대하지 않는다.
- 공급 경험을 전체 사업장·전체 설비의 유지보수 수행으로 확대하지 않는다.
- 고객사 승인 없이 로고, 현장명, 프로젝트, 수량, 금액과 사진을 공개하지 않는다.
- GS칼텍스를 EGO가 공급하는 브랜드나 EGO 사업영역의 하나처럼 표시하지 않는다.

### EGO 관련

- 제조, 공사, 설계, 설치, 시운전과 직접 수리를 확인 없이 주장하지 않는다.
- 전문인력 수, 처리율, 납기 준수율, 프로젝트 수와 업력을 근거 없이 만들지 않는다.
- 고객 운영의 안정성에 “기여”한다고 표현할 수는 있으나 운영 결과를 “보장”한다고 쓰지 않는다.

## 16.4 수치·기간·성과 표현 원칙

- 설립연도, 업력, 임직원 수, 프로젝트 수와 공급 수량은 공식 자료와 일치할 때만 표시한다.
- “다년간”, “오랜 기간”, “수십 건” 등 모호한 기간·수량 표현도 근거가 없으면 사용하지 않는다.
- 장애 처리시간, 납기 준수율과 고객 만족도는 산출 기준과 승인 자료가 있을 때만 사용한다.
- 프로젝트 성과는 EGO의 역할과 결과 사이의 인과관계를 과장하지 않는다.
- 고객사명을 공개할 수 없으면 업종·현장 유형과 EGO의 역할만 설명하되, 실제보다 넓은 범위를 암시하지 않는다.

## 16.5 최종 미확정 정보 처리

공개 전까지 해결되지 않은 항목은 다음 원칙으로 처리한다.

1. 페이지 구성상 필수인 정보는 [입력 필요] 상태를 콘텐츠 작업 목록에 남긴다.
2. 사용자 화면에 대괄호 문구를 그대로 공개하지 않는다.
3. 사실이 없어도 무리하게 채우지 않고 해당 카드·행·섹션을 숨긴다.
4. 정보가 없어도 필요한 문의 행동은 일반 안내 문구와 CTA로 유지한다.
5. 추후 정보를 받으면 이 문서의 템플릿 형식에 맞춰 사실·권리·공개 범위를 함께 확인한다.
