# Reference Research Summary

> 조사 방법: 레퍼런스 사이트 직접 접근이 네트워크 정책상 일부 차단되어, 검색 인덱스에 노출된 실제 페이지 콘텐츠·URL 구조·공개 자료를 수집해 분석함.

## 1. LS ELECTRIC (ls-electric.com)
- **IA**: 최상위를 제품 유형이 아닌 "Smart Power / Automation / Energy Solution" 3대 솔루션으로 구성. 기기를 팔지만 솔루션으로 포장하는 구조.
- **Power Distribution 분류**: MV SWGR → LV SWGR → MCC → Transformer → Busway — 전기실 단선도 순서 그대로. 구매자(공장 전기팀)의 멘탈 모델과 일치.
- **SCADA**: ECMS / PQMS / SAS를 하드웨어와 분리된 시스템 계층으로 배치.
- **톤**: 짧은 기능 정의문 중심, 상세 스펙은 카탈로그 PDF로 위임. "기기 내장 센서 + 디지털 기술로 감시·예방관리" — 하드웨어보다 모니터링 가치를 앞세움.
- **EZIO 적용**: 제품 IA를 단선도 순서로 구성. Solutions → Products 2단 구조. 스펙 나열 대신 짧은 기능 정의.

## 2. GS Caltex (gscaltex.com)
- **히어로**: 풀블리드 정유설비 이미지/영상 + 짧은 대형 헤드라인. "규모의 미학" 연출.
- **DX 메시징**: 지능형 공장 전환, AI 이상징후 조기 감지, 공정 최적화, 디지털 안전관리.
- **톤**: 큰 헤드라인 + 넉넉한 여백 + 섹션 단위 스크롤 스토리텔링.
- **EZIO 적용**: End customer가 쓰는 어휘("안정적 운영", "감시", "무정전")로 가치 제안 작성. Concept 01 히어로 구성에 반영.

## 3. Schneider Electric (se.com)
- **솔루션 셀링**: EcoStruxure 3계층(Connected Products → Edge Control → Apps/Analytics) — "제품이 아니라 데이터와 인사이트가 최종 가치"라는 피라미드 서사.
- **가치 언어**: Reliability · Safety · Efficiency · Power Quality · Monitoring 명사군이 헤드라인을 구성. 문제 정의(다운타임, 노후설비) → 가치 → 솔루션 → 상담 CTA 순서.
- **CTA**: 구매가 아닌 상담/데모 중심.
- **EZIO 적용**: Concept 03의 "현장 기기 → 데이터 → 감시" 스택 서사. 고객가치 명사 중심 카피. Contact CTA를 "프로젝트 상담"으로.

## 4. Siemens (siemens.com)
- **비주얼**: 단일 브랜드 컬러 + 무채색, 위계는 서체 굵기·크기만으로 표현하는 유럽 엔지니어링 타이포그래피. 대형 현장 사진 + 넓은 여백.
- **IA**: 전압 레벨/계통 위치 기준(Low-voltage → Medium-voltage → Energy automation → Grid software).
- **스토리**: "combine the real and the digital worlds" — 하드웨어와 소프트웨어를 항상 한 문장에.
- **EZIO 적용**: Concept 04의 절제된 타이포그래피 시스템. Concept 01의 엔지니어링 라인워크. "배전·보호 하드웨어와 감시 데이터를 하나의 시스템으로" 결합 카피.

## 조사 결과 중 채택하지 않은 것 (정확성 규칙 위반)
- "LS ELECTRIC 공식 파트너" 계열 표현 → 파트너 등급 미확인, 사용 금지
- 정량 실적 카운터("납품 N건, 무사고 N년") → 확인되지 않은 숫자 생성 금지
- 고객사 로고 월 → 사용 권한 미확인
